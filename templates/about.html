About AI Carbon Emission Monitoring System

Machine Learning methodology, environmental scoring, and map architecture

🌱 System Architecture & ML Pipeline

The AI Carbon Emission Prediction and Monitoring System utilizes Scikit-learn Machine Learning regressors trained on 5,000 environmental and consumption records across 10 Tamil Nadu districts (50 specific locations). Input parameters pass through standard preprocessing, categorical encoding, and feature scaling before model inference.

User Inputs ➔ Validation ➔ Categorical Encoding ➔ StandardScaler ➔ Regressor (.pkl) ➔ Predicted CO₂ (kg) ➔ Environmental Score & Tree Offset ➔ Leaflet Map Render

📐 Emission Factor Reference Standards

The system leverages international IPCC standard greenhouse gas emission conversion factors:

Parameter Source Conversion Unit CO₂ Emission Factor
Grid Electricity 1 kWh 0.820 kg CO₂ (Regional Tamil Nadu Grid EF)
Motor Petrol 1 Liter 2.310 kg CO₂
Automotive Diesel 1 Liter 2.680 kg CO₂
Liquefied Petroleum Gas (LPG) 1 kg 2.983 kg CO₂
Municipal Solid Waste 1 kg 0.450 kg CO₂
Public Transit (Bus/Train) 1 km 0.089 kg CO₂
Rooftop Solar PV 1 kWh -0.820 kg CO₂ (Offset)
Annual Tree Sequestration 1 Mature Tree ~21.77 kg CO₂ / year

📊 Formulas & Scoring Metrics

1. Environmental Score Calculation

The Environmental Score rates local sustainability on a scale from 0 to 100:

Score = max(0, min(100, round(100 - (Predicted_Emission / 800.0) * 100)))

2. Estimated Tree Offset Requirement

Estimates the number of mature trees required to offset the annual carbon footprint:

Tree_Offset = ceil((Predicted_Emission * 12) / 21.77)

🗺️ Map Technology: Leaflet.js + OpenStreetMap

This system integrates a fully functional, real interactive map using Leaflet.js and open-source OpenStreetMap tiles. All supported locations maintain accurate geographic coordinates (latitude and longitude) in a local database table, eliminating the need for paid geocoding APIs while supporting zooming, panning, pin markers, emission popups, and dynamic re-centering.
